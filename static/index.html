Cómo se usa

Esta web solo sirve para iniciar sesión en Spotify y comprobar que todo funciona. Las playlists se crean hablando con Claude (o ChatGPT) a través del servidor MCP, que sabe consultar tu perfil, comprobar qué conoces, buscar en Spotify y crear la playlist.
